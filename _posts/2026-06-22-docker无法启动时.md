命令行cmd里面输入
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart

等他成功
然后重启

dism.exe /online /get-featureinfo /featurename:VirtualMachinePlatform
输入这个可以检查看看启动没

应该是把虚拟什么的关掉了
  现在卡住的是 Docker/WSL 本地虚拟化环境，不是网络。报错是：

  failed to connect to dockerDesktopLinuxEngine
  The system cannot find the file specified

  以及 WSL 报：

  这类错误通常表示 Windows 的虚拟机平台/Hyper-V 相关组件没正常启用或没启动。前面我们查到：

  Microsoft-Windows-Subsystem-Linux: Enabled
  Docker Desktop 用 WSL2 后端时需要 VirtualMachinePlatform。所以要完整本地测试，需要先启用它并重启电脑。
